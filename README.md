# Luis Steven Vargas Rodríguez

Full-Stack Developer (.NET / C# · Angular · Python) based in Costa Rica.

I build backend systems and full-stack web applications end to end: REST APIs with ASP.NET Core, relational data models, JWT-based authentication, and Angular front ends on top. Most of the projects below started as real problems for real businesses (a gym, a construction company, a small store), not tutorials.

## Tech stack

**Backend:** C#, ASP.NET Core Web API, Entity Framework Core, JWT authentication, RESTful API design, Swagger / OpenAPI, Node.js, Express

**Frontend:** Angular (standalone components), TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS

**Data:** SQL Server, PostgreSQL

**Testing & practices:** xUnit, FluentAssertions, layered / Clean Architecture, Git & GitHub

**Currently learning:** Python for backend/automation, and applying AI tooling to day-to-day development workflows
